# Лабораторная работа №2. Модели, админ-панель и вывод данных в шаблон

Мини-магазин: покупатели, товары и корзины.

## Модели (`shop/models.py`)

| Модель | Поля |
|---|---|
| `Customer` — покупатель | ФИО, e-mail (уникальный), телефон, дата регистрации |
| `Product` — товар | название, категория, цена, в наличии |
| `Cart` — корзина | покупатель (`ForeignKey`), товары (`ManyToManyField`), статус (`choices`), дата создания |

Статусы корзины: «Активна», «Оформлена», «Оплачена», «Отменена».
Свойство `Cart.total_price` считает сумму товаров.

Миграции: `0001_initial` — схема, `0002_seed_data` — тестовые данные (4 покупателя, 8 товаров, 6 корзин).

## Страница `/carts/`

* `views.cart_list` загружает корзины с `select_related` и `prefetch_related`, чтобы не было лишних запросов.
* Для каждой корзины выводятся покупатель (имя, e-mail, телефон), список товаров с ценами,
  количество товаров, итоговая сумма, дата создания и статус (цветной бейдж).
* Есть поиск (`?q=`) и фильтр по статусу (`?status=`).
* Шаблон `shop/cart_list.html` наследуется от `base.html`, стили лежат в `static/css/style.css`
